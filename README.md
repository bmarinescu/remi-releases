# Remi: desktop downloads

Remi pe tablă, Remi etalat, Liber, Okey and 101 Okey in 3D, against bots or online with people. Free, no accounts,
no chips, ten languages.

- **Play in the browser, phones included:** https://remi.gitswarm.com
- **The desktop game for Windows and Linux:** the zips under [Releases](../../releases). Each zip has a README.txt
  that says how to start it and what it needs (64-bit Windows 10 or 11; or 64-bit Linux with a Vulkan driver).

This repository holds only the release files; it has no source code.
